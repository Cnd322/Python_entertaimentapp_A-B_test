# Python_entertaimentapp_A-B_test

Исследовательский анализ нового рекомендательного алгоритма
Цели и задачи проекта: Команда разработчиков рекомендательных систем создала новый алгоритм рекомендаций, который, по их мнению, будет показывать более интересный контент для каждого пользователя. Необходимо рассчитать параметры A/B-теста, который позволит проверить эту гипотезу, и проанализировать его результаты.

 Структура проекта
* Загрузка данных и знакомство с ними
* Предобработка данных
* Исследовательский анализ данных
* Расчет метрик и постановка гипотез A/B тестирования
* Мониторинг A/B тестирования
* Статистический анализ
* Итоговые выводы
   Содержание анализа
* Загрузка данных и знакомство с ними. Изучим датафреймы и посмотрим на тип данных в них.
* Проведение предобработки данных. Проведем преобразование типов данных, изучим NaN значения и дубликаты.
* Проведение исследовательского анализа данных:
* Анализ числа регистраций в приложении.
* Анализ числа просмотренных страниц.
* Доля пользователей, просмотревших более четырёх страниц.
* Расчёт размера выборки, длительности тестирования и формирование гипотез H0 и H1
* Проверка распределения основных показателей в первый день A/B тестирования
* Проверка корректности результатов теста через T-test среднего кол-ва сессий между группами
* Z-test доли успешных сессий (просмотрено более 3х страниц за одну сессию) для проверки гипотез A/B теста.
* Формулирование итогового вывода и рекомендаций
